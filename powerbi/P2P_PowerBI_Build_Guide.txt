FILES TO LOAD
1. Cases table:
   P2P_PowerBI_Cases.csv

2. Events table:
   Your original output.csv

MODEL
Cases[Case ID] 1 ---- * Events[case:concept:name]

Use single-direction filtering from Cases to Events.

Rename the Events fields in Power Query:
case:concept:name -> Case ID
concept:name -> Activity
time:timestamp -> Event Timestamp
org:resource -> Resource
case:Vendor -> Vendor
case:Company -> Company
case:Spend area text -> Spend Area
case:Sub spend area text -> Sub Spend Area
case:Document Type -> Document Type
case:Item Category -> Item Category

------------------------------------------------------------
ANALYTICAL BOUNDARIES
------------------------------------------------------------
Do not present:
Exception = Fraud
Rare Variant = Non-compliance
Repeated Activity = Confirmed Rework
High Vendor Exception Rate = Poor Supplier
Association = Causation

Investigation Priority is an operational review aid only.
